# Проанализируйте схему и описание системы

## Система состоит из трёх приложений:
-   Онлайн-магазин — написан на Vue и Java Spring Boot.
-   CRM — SPA-приложение, фронтэнд написан на Vue, бэкенд — на Java Spring Boot.
-   MES — SPA-приложение, фронтенд написан на React, бэкенд — на C#.


-   Каждое приложение имеет по одному инстансу
-   Базы данных имеют один инстанс, который работает на запись и на чтение.


-   Единая БД для Онлайн-магазина и CRM
-   Между CRM и MES настроена RabbitMQ
-   Хранилище 3d файлов с додступом из Онлайн-магазина, CRM и MES

## Проблемы компании и инициативы по их устранению

| Проблемы                                                   | Инициативы                                        |
|------------------------------------------------------------|---------------------------------------------------|
| отсутствие наблюдаемости                                   | настроить мониторинг и логирование                |
| задержки по заказам                                        | настроить параллельную обработку заказов          |
| пользователи API не получают заказы                        | настроить фильтрацию заказов в API                |
| долгая загрузка стартовой страницы MES                     | добавить кеширование запросов                     |
| тормоза при отображении всех заказов MES                   | добавить пагинацию списка заказов                 |
| тормоза при фильтрации заказов MES                         | настроить индексирование в БД                     |
| важно видеть самые новые заказы                            | настроить фильтрацию по умолчанию на новые заказы |
| потеряно несколько крупных заказов                         | настроить приоритеты к заказам                    |
| расчет стоимости заказов от 2 до 30 минут                  | настроить асинхронный расчет с уведомлением       |
| производственные мощности могут обеспечить двукратный рост | настроить горизонтальное масштабирование          |
